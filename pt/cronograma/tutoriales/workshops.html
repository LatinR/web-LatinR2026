Automate the publication of your reports with Quarto and GitHub Actions

Learn to implement a continuous deployment workflow to automate the generation and publication of reports using Quarto and GitHub Actions

About the course

Language: Spanish

The objective of the workshop is to learn how to automate the publication and updates of R and Quarto projects through GitHub Actions and GitHub Pages. This will allow participants to improve the efficiency, reproducibility and accessibility of their analyses and reports, facilitating the open dissemination of results.

Instructor

Jesica Formoso is a cognitive psychologist, PhD from the University of Buenos Aires and CONICET researcher in Argentina. Specialized in statistics applied to health sciences, she is a certified Posit and The Carpentries instructor. She researches text comprehension in children and advises projects in methodological design, data analysis and development of reproducible tools. She is co-organizer at R-Ladies Buenos Aires and collaborates with R-Ladies Global and the Forwards community. Additionally, she is part of the MetaDocencia team, where she coordinates the impact measurement area.

Making great slides with quarto and revealjs

Learn to make great slides in Quarto using the revealjs output format

About the course

Language: English

This workshop is all about making great slides in Quarto! You don’t need to be a Quarto expert in order to participate, but having some basic knowledge of Quarto would be helpful. We will start with the basics of making a slide deck in Quarto using the revealjs output format and progress through lots of tips and tricks to help you get the most out of your slidecrafting experience. We will cover everything from styling and theming to how to best position elements on your slides for the best outcome.

Instructor

Emil Hvitfeldt is a software engineer at Posit and part of the tidymodels team’s effort to improve R’s modeling capabilities. He maintains several packages within the realms of modeling, text analysis, and color palettes. Trying to make slidecrafting a well respecting verb. He co-authored the book Supervised Machine Learning for Text Analysis in R with Julia Silge. Working on book Feature Engineering A-Z.

LLMs in R using {ellmer}

Learn to use LLMs programmatically in R with {ellmer}

About the course

Language: English

In this workshop we’ll explore using LLMs programmatically in R with ellmer. We’ll cover at the key concepts to understand, and you’ll learn how to connect to LLM APIs, extract structured data from unstructured text, and how to let LLMs call R functions and access external sources for more reliable results.

Instructor

Nic Crane is an open-source maintainer and independent R consultant and educator. They are a member of the Apache Arrow Project Management Committee and one of the maintainers of the Arrow R package, contributing to the broader Arrow ecosystem and its adoption across data science workflows. Nic is a contributor to the ellmer R package and teaches and writes about using LLMs in R.

From idea to package: program your first R package

Hands-on workshop to turn an idea into an R package, from project setup to publication

Shiny + ellmer: patterns for connecting conversation, data, and interface

Hands-on workshop to add artificial intelligence to your Shiny applications

About the course

Language: Spanish

This is a hands-on workshop that walks step by step through different ways of incorporating language models into a Shiny application using ellmer. We will start from a simple application and add conversation, controlled access to data, SQL queries, state updates, and actions on the interface, ending with a conversational dashboard that controls charts, tables, and maps.

Each pattern is presented as an independent application that changes a single idea relative to the previous one. This makes it possible to clearly identify what code enables each pattern, when it is useful, and what validations it requires. The goal is not to replace the traditional interface with a chat, but to understand how both forms of interaction can complement each other.

Instructor

Joshua Kunst
