### LatinR 2026 Tutorials

![Photos from past editions of LatinR tutorials](/img/posts/tutoriales.jpg){fig-alt="Person participating in a tutorial at LatinR" width="100%"}

<br> The ninth edition of LatinR is coming soon! This year, in addition to talks and interactive sessions, we will have a wide variety of hands-on tutorials led by specialists from the R community. Here's what each one will cover.

<br>

#### Automate the publication of your reports with Quarto and GitHub Actions

![Flyer for the tutorial "Automate the publication of your reports with Quarto and GitHub Actions"](/img/posts/tutorial_quarto-github-actions.png){fig-alt="Flyer for the tutorial Automate the publication of your reports with Quarto and GitHub Actions" width="100%"}

**Language:** Spanish

The objective of the workshop is to learn how to automate the publication and updates of R and Quarto projects through GitHub Actions and GitHub Pages. Starting from an already prepared Google Form and a Quarto dashboard, participants will configure a GitHub repository and a YAML workflow to retrieve data from Google Sheets, process it with R, generate the dashboard, and automatically publish it to GitHub Pages at regular intervals. It is aimed at people who work with R and Quarto or RMarkdown and want to improve the efficiency, reproducibility, accessibility, and dissemination of their analyses, reports, and dashboards.

**Instructor:** Jesica Formoso

<br>

#### Making great slides with Quarto and revealjs

![Flyer for the tutorial "Making great slides with Quarto and revealjs"](/img/posts/tutorial-slides-quarto.png){fig-alt="Flyer for the tutorial Making great slides with Quarto and revealjs" width="100%"}

**Language:** English

This workshop is all about making great slides in Quarto! You don't need to be a Quarto expert in order to participate, but having some basic knowledge of Quarto would be helpful. We will start with the basics of making a slide deck in Quarto using the revealjs output format and progress through lots of tips and tricks to help you get the most out of your slidecrafting experience. We will cover everything from styling and theming to how to best position elements on your slides for the best outcome.

**Instructor:** Emil Hvitfeldt

<br>

#### LLMs in R using {ellmer}

![Flyer for the tutorial "LLMs in R using {ellmer}"](/img/posts/tutorial-llms-en-r-con-ellmer.png){fig-alt="Flyer for the tutorial LLMs in R using ellmer" width="100%"}

**Language:** English

In this workshop we'll explore using LLMs programmatically in R with ellmer. We'll cover the key concepts to understand, and you'll learn how to connect to LLM APIs, extract structured data from unstructured text, and how to let LLMs call R functions and access external sources for more reliable results.

**Instructor:** Nic Crane

<br>

#### Building Machine Learning Models with tidymodels: A Hands-on Tutorial

![Flyer for the tutorial "Building Machine Learning Models with tidymodels: A Hands-on Tutorial"](/img/posts/tutorial_tidymodels.png){fig-alt="Flyer for the tutorial Building Machine Learning Models with tidymodels" width="100%"}

**Language:** Spanish

This is a hands-on workshop that presents, step by step, the workflow for building Machine Learning models in R using tidymodels. We will explore some of the ecosystem's main tools for working with data, defining models, and organizing a reproducible modeling process. Through applied examples, we will review the different stages of the process, from data preparation to model performance evaluation, aiming to offer a general and practical overview of the possibilities tidymodels offers for developing Machine Learning models in R.

**Instructor:** Freddy Hernández-Barajas

<br>

#### From idea to package: program your first R package

![Flyer for the tutorial "From idea to package: program your first R package"](/img/posts/tutorial-de-idea-a-paquete.png){fig-alt="Flyer for the tutorial From idea to package" width="100%"}

**Language:** Spanish

In this hands-on workshop you will learn how to turn an idea into an R package, going through the main stages of the development process: project organization, coding, documentation, testing, and publication. We will also discuss the use of AI (GitHub Copilot) as an assistant during the development of your package.

**Instructor:** Yanina Bellini Saibene

<br>

#### Shiny + ellmer: patterns for connecting conversation, data, and interface

![Flyer for the tutorial "Shiny + ellmer: patterns for connecting conversation, data, and interface"](/img/posts/tutorial-shiny-ellmer.png){fig-alt="Flyer for the tutorial Shiny + ellmer" width="100%"}

**Language:** Spanish

This is a hands-on workshop that walks step by step through different ways of incorporating language models into a Shiny application using ellmer. We will start from a simple application and add conversation, controlled access to data, SQL queries, state updates, and actions on the interface, ending with a conversational dashboard that controls charts, tables, and maps.

Each pattern is presented as an independent application that changes a single idea relative to the previous one. This makes it possible to clearly identify what code enables each pattern, when it is useful, and what validations it requires. The goal is not to replace the traditional interface with a chat, but to understand how both forms of interaction can complement each other.

**Instructor:** Joshua Kunst
